# 🔌 Myspoti SakuKelly Extension

Extensión complementaria y módulo auxiliar para el ecosistema **Myspoti (SakuKelly Edition)** en Android y navegadores web.

---

## ⚡ Características

- Integración directa con el motor de audio y streaming de **Myspoti SakuKelly**.
- Captura optimizada de metadatos, letras y carátulas en alta resolución.
- Canal de comunicación ligero y seguro para descargas locales sin pérdida de calidad.

---
